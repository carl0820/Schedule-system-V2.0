# 多机器人调度系统 - 产品需求文档（PRD）

## 1. 项目概述

### 1.1 项目背景
随着多机器人协同作业需求的增长，需要一套可靠的多机器人调度系统，确保多台机器人在同一场景下安全、高效地协同工作，避免碰撞和冲突。

### 1.2 项目目标
基于思岚科技底盘REST API和栅格地图，构建一套多机器人调度系统，实现：
- 多台机器人在同一场景下的协同调度
- 实时碰撞检测与避免
- 高效的任务分配与路径规划
- 稳定可靠的系统运行

### 1.3 目标用户
- 仓储物流场景
- 工厂生产车间
- 服务机器人场景
- 其他需要多机器人协同的应用场景

## 2. 功能需求

### 2.1 核心功能

#### 2.1.1 地图管理
- **功能描述**：支持栅格地图的加载、显示和管理
- **详细需求**：
  - 支持二进制字节流栅格地图格式（通过 `/api/core/slam/v1/maps/explore` 获取）
  - 支持STCM格式地图（思岚科技专有格式，通过 `/api/multi-floor/map/v1/stcm/:sync` 同步）
  - 地图分辨率可配置
  - 支持地图的实时更新（动态障碍物）
  - 地图坐标与世界坐标的双向转换
  - 障碍物标记与清除

#### 2.1.2 机器人管理
- **功能描述**：管理多台机器人的注册、状态监控和生命周期
- **详细需求**：
  - 机器人注册与认证
  - 实时位置与姿态获取
  - 速度、电量等状态监控
  - 机器人上下线管理
  - 机器人异常检测与处理

#### 2.1.3 任务调度
- **功能描述**：接收任务请求，分配任务给合适的机器人
- **详细需求**：
  - 任务创建（起点、终点、优先级）
  - 任务队列管理（优先级队列）
  - 智能任务分配（基于距离、负载、电量）
  - 任务状态跟踪（待分配、执行中、已完成、失败）
  - 任务取消与重试机制
  - 任务执行历史记录

#### 2.1.4 路径规划
- **功能描述**：为机器人规划从起点到终点的最优路径
- **详细需求**：
  - 全局路径规划（A*算法）
  - 路径平滑处理
  - 动态路径调整（遇到障碍物时）
  - 多路径冲突检测
  - 路径可视化

#### 2.1.5 碰撞避免
- **功能描述**：实时检测并避免多机器人之间的碰撞
- **详细需求**：
  - 时间窗口预测（预测未来N秒轨迹）
  - 实时碰撞检测（时间-空间重叠检测）
  - 避让策略（等待、绕行、减速）
  - 优先级机制（任务优先级 + 距离优先）
  - 死锁检测与自动恢复
  - 动态障碍物避让

### 2.2 辅助功能

#### 2.2.1 可视化监控
- **功能描述**：提供Web界面实时监控系统状态
- **详细需求**：
  - 地图可视化显示
  - 机器人位置实时显示
  - 路径规划可视化
  - 任务状态列表
  - 系统性能指标（CPU、内存、网络）
  - 告警信息显示

#### 2.2.2 日志管理
- **功能描述**：记录系统运行日志，便于问题排查
- **详细需求**：
  - 任务执行日志
  - 碰撞事件日志
  - 异常错误日志
  - 日志分级（DEBUG、INFO、WARNING、ERROR）
  - 日志查询与导出

#### 2.2.3 系统配置
- **功能描述**：系统参数配置管理
- **详细需求**：
  - 地图配置（分辨率、原点坐标）
  - 机器人参数配置（最大速度、加速度）
  - 碰撞避免参数（预测时间窗口、安全距离）
  - 路径规划参数（算法选择、权重）
  - 配置文件热更新

## 3. 非功能需求

### 3.1 性能需求
- **响应时间**：任务分配响应时间 < 500ms
- **路径规划**：单次路径规划时间 < 1s
- **碰撞检测**：检测频率 ≥ 10Hz
- **并发支持**：支持至少10台机器人同时运行
- **系统吞吐**：支持每秒至少5个任务请求

### 3.2 可靠性需求
- **系统可用性**：≥ 99.5%
- **故障恢复**：系统故障后自动恢复时间 < 30s
- **数据一致性**：确保多机器人状态数据一致性
- **异常处理**：机器人离线不影响其他机器人运行

### 3.3 安全性需求
- **通信安全**：支持HTTPS/WSS加密通信
- **身份认证**：机器人注册需要认证
- **权限控制**：不同用户角色权限管理
- **数据安全**：敏感数据加密存储

### 3.4 可维护性需求
- **代码规范**：遵循Python PEP8规范
- **文档完善**：提供API文档、部署文档、运维文档
- **模块化设计**：模块低耦合、高内聚
- **可扩展性**：支持新功能模块的灵活接入

## 4. 技术架构

### 4.1 系统架构
```
┌─────────────────────────────────────────┐
│        Web前端（可视化界面）              │
└─────────────────────────────────────────┘
           ↕ HTTP/WebSocket
┌─────────────────────────────────────────┐
│       调度中心服务（核心调度）            │
│  - FastAPI REST API                     │
│  - WebSocket实时通信                    │
│  - 任务调度模块                         │
│  - 路径规划模块                         │
│  - 碰撞避免模块                         │
└─────────────────────────────────────────┘
           ↕ HTTP REST API
┌─────────────────────────────────────────┐
│       机器人代理层（Agent）              │
│  - 思岚科技底盘API封装                  │
│  - 状态上报                             │
│  - 指令执行                             │
└─────────────────────────────────────────┘
           ↕ REST API
┌─────────────────────────────────────────┐
│       思岚科技底盘（硬件）                │
└─────────────────────────────────────────┘
```

### 4.2 技术栈
- **后端框架**：Python 3.8+ + FastAPI
- **通信协议**：HTTP REST API + WebSocket
- **路径规划**：A*算法 + DWA局部避障
- **地图管理**：栅格地图（Occupancy Grid Map）
- **数据存储**：Redis（实时状态）+ PostgreSQL（历史数据）
- **前端框架**：React/Vue.js（可选）
- **部署方式**：Docker容器化部署

### 4.3 核心算法
- **全局路径规划**：A*算法
- **局部路径优化**：DWA（Dynamic Window Approach）
- **碰撞避免**：时间窗口预测 + 优先级调度
- **任务分配**：最短路径优先 + 负载均衡

## 5. 接口需求

### 5.1 思岚科技底盘API集成（具体的见API.md）
- **机器人状态获取**：位置、姿态、速度、电量
- **运动控制**：速度指令、目标点导航
- **传感器数据**：激光雷达、里程计等（如有）

### 5.2 调度系统API
- **任务管理**：创建任务、查询任务、取消任务

- **地图管理**：加载地图、更新地图、查询地图信息
- **系统监控**：获取系统状态、性能指标、告警信息

## 6. 数据需求

### 6.1 地图数据
- **格式**：
  - **二进制字节流栅格地图**（通过 `/api/core/slam/v1/maps/explore` 获取）
    - 前32字节为元数据（起始位置X/Y坐标、X/Y轴栅格数量、地图分辨率等，低位字节在前）
    - 后续为地图数据（每个字节代表一个格子）
    - 可通过min_x, min_y, max_x, max_y指定获取的范围
  - **STCM格式**（思岚科技专有格式，通过 `/api/multi-floor/map/v1/stcm/:sync` 同步）
- **分辨率**：可配置（推荐0.05m/pixel）
- **坐标系**：世界坐标系（x, y, theta）

### 6.2 机器人状态数据
- **位置信息**：x, y, theta（世界坐标）
- **速度信息**：线速度、角速度
- **状态信息**：电量、任务状态、健康状态
- **更新时间**：时间戳

### 6.3 任务数据
- **任务ID**：唯一标识
- **起点终点**：坐标信息
- **优先级**：任务优先级
- **状态**：任务执行状态
- **创建时间**：时间戳

## 7. 用户界面需求

### 7.1 Web监控界面
- **地图显示**：实时显示地图和机器人位置
- **任务管理**：创建任务、查看任务列表

## 8. 部署需求

### 8.1 硬件要求
- **服务器**：CPU 4核+，内存 8GB+，存储 50GB+
- **网络**：局域网，延迟 < 50ms
- **机器人**：支持思岚科技底盘REST API

### 8.2 软件环境
- **操作系统**：Linux（Ubuntu 20.04+）或 Windows Server
- **Python版本**：Python 3.8+
- **数据库**：PostgreSQL 12+，Redis 6+
- **容器**：Docker 20.10+（可选）
