# 4-8台机器人死锁解除策略确认文档

## 概述

本文档确认当前系统中针对4-8台机器人场景的死锁解除策略。系统根据死锁类型和涉及的机器人数量，动态调整让行策略，确保快速高效地解除死锁。

## 死锁解除策略详细说明

### 1. 窄道死锁（Narrow Passage Deadlock）

**函数**: `_resolve_narrow_passage_deadlock()`

**策略**:
- **2-3台机器人**: 让 **1台** 低优先级机器人后退或移动到等待点
- **4-5台机器人**: 让 **一半**（2-3台）低优先级机器人后退
  - 计算公式: `max(2, num_robots // 2)`
  - 4台 → 2台
  - 5台 → 2台（向上取整为2）
- **6台或更多机器人**: 让 **1/3**（至少2台）低优先级机器人后退
  - 计算公式: `max(2, (num_robots + 2) // 3)`
  - 6台 → 2台
  - 7台 → 3台
  - 8台 → 3台

**代码位置**: `app/services/deadlock_detector.py:1464-1621`

---

### 2. 循环等待死锁（Circular Wait Deadlock）

**函数**: `_resolve_circular_wait_deadlock()`

**策略**:
- **2-3台机器人**: 让 **1台** 低优先级机器人后退或移动到等待点
- **4-5台机器人**: 让 **一半**（2-3台）低优先级机器人后退
  - 计算公式: `max(2, num_robots // 2)`
  - 4台 → 2台
  - 5台 → 2台
- **6台或更多机器人**: 让 **1/3**（至少2台）低优先级机器人后退
  - 计算公式: `max(2, (num_robots + 2) // 3)`
  - 6台 → 2台
  - 7台 → 3台
  - 8台 → 3台

**代码位置**: `app/services/deadlock_detector.py:1623-1789`

---

### 3. 相互阻塞死锁（Mutual Blocking Deadlock）

**函数**: `_resolve_mutual_blocking_deadlock()`

**策略**（使用更激进的策略）:
- **2-3台机器人**: 让 **1台** 低优先级机器人后退
- **4台机器人**: 让 **2台** 低优先级机器人后退（固定值）
- **5-6台机器人**: 让 **一半**（2-3台）低优先级机器人后退
  - 计算公式: `max(2, num_robots // 2)`
  - 5台 → 2台
  - 6台 → 3台
- **7-8台机器人**: 让 **一半**（至少3台）低优先级机器人后退（更激进）
  - 计算公式: `max(3, num_robots // 2)`
  - 7台 → 3台
  - 8台 → 4台

**代码位置**: `app/services/deadlock_detector.py:1791-2103`

**特殊处理**:
- 优先让没有任务的机器人避让
- 如果所有机器人都有任务，按综合优先级排序（考虑任务优先级、距离、执行时间、剩余动作数）

## 机器人选择策略

所有死锁类型都使用以下优先级排序策略：

1. **综合优先级计算** (`_get_robot_task_priority_with_state`):
   - 任务优先级（数值越小，优先级越低）
   - 任务执行时间（执行时间越长，优先级越低）
   - 任务完成进度（剩余动作越多，优先级越低）
   - 距离因素（距离越近，优先级越低）

2. **特殊处理**（仅相互阻塞死锁）:
   - 优先让没有任务的机器人避让
   - 没有任务的机器人按距离排序（距离近的优先避让）

3. **避让方式**:
   - 优先使用等待点（系统自动计算，距离2-5米）
   - 如果找不到等待点，使用后退策略（后退1.0-1.5米）

## 实际应用示例

### 示例1: 4台机器人在窄道相遇
- **死锁类型**: 窄道死锁
- **让行数量**: 2台低优先级机器人
- **结果**: 2台机器人移动到等待点或后退，另外2台继续执行任务

### 示例2: 6台机器人在十字路口相遇
- **死锁类型**: 循环等待死锁
- **让行数量**: 2台低优先级机器人
- **结果**: 2台机器人移动到等待点，另外4台继续执行任务

### 示例3: 8台机器人在长走廊相向而行
- **死锁类型**: 相互阻塞死锁
- **让行数量**: 4台低优先级机器人（更激进策略）
- **结果**: 4台机器人后退，另外4台继续执行任务

## 验证方法

1. **查看日志**: 死锁解除时会输出详细的日志信息，包括：
   - 死锁类型
   - 涉及的机器人数量
   - 选择的让行机器人数量
   - 每个机器人的优先级信息

2. **监控任务状态**: 确保被选中的机器人能够成功移动到等待点或后退，任务能够恢复执行

3. **性能指标**:
   - 死锁检测频率: 每0.5秒一次
   - 死锁解决时间: 通常 < 5秒（从检测到解决）
   - 任务完成率: 预期 > 95%

## 注意事项

1. **优先级设置**: 合理设置任务优先级，确保低优先级任务能够被选中避让
2. **地图宽度**: 确保地图中的通道宽度至少为1.8米（2个机器人旋转直径）
3. **等待点有效性**: 等待点需要在地图加载后计算，确保位置有效且不与其他机器人冲突
4. **避让距离**: 避让距离需要足够远（至少3米），确保真正解除阻塞
