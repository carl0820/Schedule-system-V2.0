# 🚀 新手快速开始指南

> 适合完全没有编程基础的用户，3分钟完成部署

## 📋 需要准备的东西

- ✅ Windows 10 或 Windows 11 电脑
- ✅ 能访问互联网
- ✅ 与机器人在同一网络（或通过VPN连接）

## 🎯 三步部署

### 第一步：下载代码

1. 打开浏览器，访问：https://github.com/carl0820/Schedule-system-V2.0
2. 点击绿色的 **"Code"** 按钮
3. 选择 **"Download ZIP"**
4. 下载完成后，**右键解压**到任意位置（例如：`D:\chatbot`）

### 第二步：安装Python（如果还没有）

1. 访问：https://www.python.org/downloads/
2. 点击黄色的 **"Download Python 3.x.x"** 按钮
3. 下载完成后，**双击**安装程序
4. **⚠️ 重要**：勾选 **"Add Python to PATH"**（页面最下方的复选框）
5. 点击 **"Install Now"**
6. 等待安装完成

### 第三步：一键部署

1. 打开解压后的文件夹（例如：`D:\chatbot`）
2. **双击** `deploy.bat` 文件（如果双击不起作用，右键选择"以管理员身份运行"）
3. 等待自动安装依赖（第一次需要1-3分钟）
4. 看到 "Uvicorn running on http://0.0.0.0:8092" 就成功了！

**💡 提示**：
- 如果双击后窗口一闪就消失，请右键选择"以管理员身份运行"
- 或者在文件夹地址栏输入 `cmd` 回车，然后输入 `deploy.bat` 回车

## ✅ 使用系统

打开浏览器，访问：http://localhost:8092

你会看到：
- 📍 **主页面**：实时地图和机器人位置
- 🤖 **机器人管理**：点击右上角菜单注册机器人
- 📋 **任务管理**：查看和管理任务
- 🗺️ **地图管理**：配置地图和POI

## 🤖 注册机器人

1. 在主页面点击右上角 **"配置"** → **"机器人管理"**
2. 点击 **"注册机器人"**
3. 填写信息：
   - **机器人ID**：随便起个名字（例如：Robot1、Apollo）
   - **IP地址**：机器人的IP地址（例如：192.168.1.100）
   - **端口**：通常是 `1448`
4. 点击 **"注册"**

## 📝 创建任务

### 方法1：通过地图（最简单）

1. 在主页面，从 **"目标POI"** 下拉框选择一个地点
2. 点击 **"创建单动作任务"**
3. 系统会自动分配机器人执行任务

### 方法2：手动输入坐标

1. 在主页面，输入目标坐标：
   - **X坐标**、**Y坐标**、**朝向**
2. 点击 **"创建单动作任务"**

## 🔄 下次启动

**已经部署过一次？**

下次只需要：
1. 打开项目文件夹
2. **双击** `start.bat`（如果不起作用，右键"以管理员身份运行"）
3. 等待启动完成

**💡 提示**：
- 推荐在文件夹地址栏输入 `cmd` 后回车，然后输入 `start.bat` 启动
- 或者使用PowerShell：在文件夹空白处按住Shift+右键，选择"在此处打开PowerShell窗口"，输入 `.\start.ps1`

## ❓ 常见问题

### 问题1：双击 deploy.bat 后一闪就消失了

**原因**：可能没有安装Python或Python未加入PATH

**解决**：
1. 按照"第二步"重新安装Python
2. 务必勾选 "Add Python to PATH"

### 问题2：提示"未找到可用的Python环境"

**解决**：
1. 确认Python已安装：开始菜单搜索"Python"
2. 重新安装Python，勾选 "Add Python to PATH"
3. 重启电脑后再试

### 问题3：依赖安装失败

**解决**：
1. 检查网络连接
2. 临时关闭防火墙或杀毒软件
3. 再次运行 `deploy.bat`

### 问题4：无法访问机器人

**解决**：
1. 确认电脑和机器人在同一网络
2. 测试机器人IP是否可达：
   - 打开命令提示符（CMD）
   - 输入：`ping 机器人IP地址`
   - 看是否有响应

### 问题5：端口8092被占用

**解决**：
1. 打开任务管理器
2. 结束占用8092端口的程序
3. 或修改端口（需要编辑代码）
