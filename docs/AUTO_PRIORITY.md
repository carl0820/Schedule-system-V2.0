# 自动优先级计算系统

## 概述

系统现在支持**完全自动的优先级计算**，无需人工干预。任务优先级会根据多个因素自动计算和动态调整。

## 优先级计算机制

### 1. 初始优先级计算

创建任务时，如果用户没有指定优先级，系统会自动计算初始优先级，考虑以下因素：

#### 因素1：任务距离
- **路径长度 > 15米**：优先级 +0.5
- **路径长度 > 8米**：优先级 +0.3
- 使用路径规划器计算实际路径长度（更准确）

#### 因素2：POI重要性
- 如果任务使用POI导航，自动提升到 **HIGH** 优先级
- POI任务通常表示重要位置，需要优先处理

#### 因素3：基础优先级
- 默认从 **NORMAL (2)** 开始
- 根据上述因素调整后，限制在 **LOW (1)** 到 **URGENT (4)** 之间

### 2. 动态优先级调整

任务创建后，系统会持续监控任务状态，并根据以下因素动态调整优先级：

#### 因素1：等待时间（最重要）

| 等待时间 | 优先级提升 |
|---------|-----------|
| ≥ 120秒 | 提升到 **URGENT (4)** |
| ≥ 60秒 | 优先级 +1.5 |
| ≥ 30秒 | 优先级 +0.8 |

**系统负载影响**：
- 如果待分配任务数量 > 5，等待时间的影响会加倍
- 确保在高负载情况下，等待任务能更快得到处理

#### 因素2：重试次数
- **重试次数 ≥ 2**：优先级 +0.5
- 重试次数多的任务通常比较重要或困难，需要优先处理

#### 因素3：任务失败后重置
- 失败后重新调度的任务：优先级 +0.3
- 给失败任务第二次机会，避免任务被长期忽略

### 3. 优先级范围

优先级始终限制在以下范围内：
- **最低**：LOW (1)
- **最高**：URGENT (4)

## 使用方式

### 方式1：完全自动（推荐）

创建任务时不指定优先级，系统自动计算：

```json
POST /api/tasks/
{
  "target_pose": {
    "x": 5.0,
    "y": 3.0,
    "yaw": 0.0
  }
  // 不指定 priority，系统自动计算
}
```

### 方式2：手动指定（可选）

如果确实需要手动指定优先级，仍然可以：

```json
POST /api/tasks/
{
  "target_pose": {
    "x": 5.0,
    "y": 3.0,
    "yaw": 0.0
  },
  "priority": 4  // 手动指定为 URGENT
}
```

**注意**：即使手动指定了优先级，系统仍会根据等待时间等因素动态调整。

## 配置参数

在 `config.py` 中可以配置以下参数：

```python
# 自动优先级计算配置
PRIORITY_WAIT_TIME_THRESHOLD_1: float = 30.0  # 等待30秒后提升优先级
PRIORITY_WAIT_TIME_THRESHOLD_2: float = 60.0  # 等待60秒后进一步提升
PRIORITY_WAIT_TIME_THRESHOLD_3: float = 120.0  # 等待120秒后提升到最高
PRIORITY_RETRY_THRESHOLD: int = 2  # 重试2次后提升优先级
```

## 优先级调整示例

### 示例1：新任务自动计算

```
任务创建：
- 路径长度：12米
- POI：无
- 初始优先级：NORMAL (2) + 0.3 = 2.3 → HIGH (3)
```

### 示例2：等待时间提升

```
任务状态变化：
- 0秒：HIGH (3)
- 30秒：HIGH (3) + 0.8 = 3.8 → URGENT (4)
- 60秒：URGENT (4)（已到最高）
```

### 示例3：重试提升

```
任务状态变化：
- 初始：NORMAL (2)
- 失败1次：NORMAL (2)
- 失败2次：NORMAL (2) + 0.5 = 2.5 → HIGH (3)
- 重置后：HIGH (3) + 0.3 = 3.3 → HIGH (3)
```

## 日志输出

系统会记录优先级计算和调整的日志：

```
INFO: Auto-calculated priority for new task: 3 (HIGH)
INFO: Task abc123 priority updated: NORMAL(2) -> HIGH(3)
```

## 优势

1. **无需人工干预**：系统自动计算和调整优先级
2. **公平性**：等待时间长的任务自动提升优先级
3. **效率**：重要任务（POI、长距离）自动获得更高优先级
4. **适应性**：根据系统负载动态调整
5. **容错性**：失败任务自动提升优先级，获得重试机会

## 注意事项

1. **优先级会动态变化**：任务等待时优先级会自动提升
2. **最高优先级限制**：优先级不会超过 URGENT (4)
3. **手动指定仍有效**：如果手动指定了优先级，系统会使用该值，但仍会根据等待时间调整
4. **路径规划依赖**：初始优先级计算需要地图已加载
