# 服务重启指南

## 快速重启方法

### 方法一：使用重启脚本（推荐）

在 PowerShell 中运行：

```powershell
.\restart_service_simple.ps1
```

这个脚本会：
1. 自动停止运行在端口 8000 的服务
2. 使用虚拟环境中的 Python 启动新服务
3. 在后台运行服务

### 方法二：手动重启

#### 步骤 1：停止当前服务

**如果服务在终端中运行：**
- 在运行服务的终端窗口中按 `Ctrl + C`

**如果服务在后台运行：**
```powershell
# 查找并停止运行在端口 8000 的进程
Get-NetTCPConnection -LocalPort 8000 -ErrorAction SilentlyContinue | 
    Select-Object -ExpandProperty OwningProcess -Unique | 
    ForEach-Object { Stop-Process -Id $_ -Force }
```

#### 步骤 2：启动服务

**使用虚拟环境（推荐）：**
```powershell
.\venv\Scripts\python.exe main.py
```

**或者直接使用 Python：**
```powershell
python main.py
```

**使用 uvicorn 命令：**
```powershell
.\venv\Scripts\python.exe -m uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

## 验证服务是否正常运行

### 1. 检查端口是否被占用
```powershell
Get-NetTCPConnection -LocalPort 8000 -ErrorAction SilentlyContinue
```

### 2. 测试健康检查接口
```powershell
Invoke-RestMethod -Uri "http://localhost:8000/health"
```

### 3. 访问 Web 界面
在浏览器中打开：
- 主页：http://localhost:8000/
- API 文档：http://localhost:8000/docs

## 常见问题

### 问题 1：端口被占用
如果端口 8000 已被占用，可以：

1. **停止占用端口的进程：**
```powershell
Get-NetTCPConnection -LocalPort 8000 -ErrorAction SilentlyContinue | 
    Select-Object -ExpandProperty OwningProcess -Unique | 
    ForEach-Object { Stop-Process -Id $_ -Force }
```

2. **使用其他端口：**
修改 `config.py` 中的 `PORT` 设置，或使用命令行参数：
```powershell
.\venv\Scripts\python.exe -m uvicorn main:app --host 0.0.0.0 --port 8001 --reload
```

### 问题 2：服务启动失败
检查：
1. **Python 环境是否正确：**
```powershell
.\venv\Scripts\python.exe --version
```

2. **依赖是否安装：**
```powershell
.\venv\Scripts\pip.exe install -r requirements.txt
```

3. **查看错误日志：**
直接在前台运行服务查看错误信息：
```powershell
.\venv\Scripts\python.exe main.py
```

### 问题 3：无法访问服务
检查：
1. 防火墙设置
2. 服务是否真的在运行（检查端口）
3. 浏览器控制台是否有错误

## 服务启动成功的标志

启动成功后，应该看到类似输出：
```
INFO:     Started server process [xxxxx]
INFO:     Waiting for application startup.
INFO:     Application startup complete.
INFO:     Uvicorn running on http://0.0.0.0:8000 (Press CTRL+C to quit)
```

## 后台运行服务

如果需要让服务在后台运行：

```powershell
# 使用 Start-Process 在后台启动
Start-Process -FilePath ".\venv\Scripts\python.exe" -ArgumentList "main.py" -WindowStyle Hidden

# 或者使用 PowerShell 作业
Start-Job -ScriptBlock { .\venv\Scripts\python.exe main.py }
```

查看后台作业：
```powershell
Get-Job
```

停止后台作业：
```powershell
Stop-Job -Name <作业名称>
Remove-Job -Name <作业名称>
```
