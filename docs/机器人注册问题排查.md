# 机器人注册问题排查指南

## 问题诊断工具

使用诊断工具来测试机器人连接：

```powershell
# 测试机器人连接（仅测试连接）
python test_robot_connection.py 10.160.128.91

# 测试机器人连接并尝试注册
python test_robot_connection.py 10.160.128.91 robot1
```

## 常见问题及解决方案

### 1. 无法连接到机器人（ConnectError）

**错误信息：**
```
Cannot connect to robot at http://10.160.128.91:1448. Please check if the robot is running and accessible.
```

**可能原因：**
- 机器人服务未运行
- 网络不可达
- IP地址或端口错误
- 防火墙阻止连接

**解决方案：**
1. 检查机器人是否运行
2. 检查IP地址是否正确：
   ```powershell
   ping 10.160.128.91
   ```
3. 检查端口是否开放：
   ```powershell
   Test-NetConnection -ComputerName 10.160.128.91 -Port 1448
   ```
4. 检查防火墙设置
5. 尝试在浏览器中访问：`http://10.160.128.91:1448/api/core/system/v1/robot/health`

### 2. 连接超时（TimeoutException）

**错误信息：**
```
Connection timeout when connecting to http://10.160.128.91:1448. The robot may be unreachable or slow to respond.
```

**可能原因：**
- 网络延迟高
- 机器人响应慢
- 防火墙阻止连接

**解决方案：**
1. 检查网络连接
2. 尝试增加超时时间（默认10秒）
3. 检查防火墙设置
4. 尝试ping机器人IP地址

### 3. HTTP错误（HTTPStatusError）

**错误信息：**
```
HTTP error 404 when connecting to http://10.160.128.91:1448. The robot API may not be available.
```

**可能原因：**
- API端点不存在
- 机器人API版本不匹配
- 机器人服务未正确启动

**解决方案：**
1. 检查机器人API文档，确认端点路径
2. 尝试访问健康检查端点：
   ```
   http://10.160.128.91:1448/api/core/system/v1/robot/health
   ```
3. 检查机器人服务日志

### 4. 数据解析错误（ValueError）

**错误信息：**
```
Failed to parse pose data: Missing required field in pose data: 'x'
```

**可能原因：**
- 机器人API返回的数据格式不匹配
- API版本不兼容

**解决方案：**
1. 检查机器人API返回的数据格式
2. 使用诊断工具查看实际返回的数据：
   ```powershell
   python test_robot_connection.py 10.160.128.91
   ```
3. 检查API版本是否匹配

### 5. URL格式错误

**错误信息：**
```
Invalid base_url format. Expected format: http://host:port or host. Got: ...
```

**解决方案：**
使用正确的URL格式：
- ✅ 正确：`10.160.128.91` 或 `http://10.160.128.91:1448`
- ❌ 错误：`http://10.160.128.91`（缺少端口）

### 6. 机器人已注册

**错误信息：**
```
Robot robot1 is already registered
```

**解决方案：**
先注销机器人，再重新注册：
```powershell
# 注销机器人
Invoke-RestMethod -Uri "http://localhost:8000/api/robots/robot1" -Method DELETE

# 重新注册
Invoke-RestMethod -Uri "http://localhost:8000/api/robots/register?robot_id=robot1&base_url=10.160.128.91" -Method POST
```

## 注册步骤

### 方法1：使用PowerShell

```powershell
# 1. 注册机器人
$response = Invoke-RestMethod -Uri "http://localhost:8000/api/robots/register?robot_id=robot1&base_url=10.160.128.91" -Method POST
Write-Host "注册结果: $($response | ConvertTo-Json)"

# 2. 检查注册状态
$robots = Invoke-RestMethod -Uri "http://localhost:8000/api/robots/" -Method GET
Write-Host "已注册的机器人: $robots"

# 3. 获取机器人状态
$state = Invoke-RestMethod -Uri "http://localhost:8000/api/robots/robot1/state" -Method GET
Write-Host "机器人状态: $($state | ConvertTo-Json)"
```

### 方法2：使用curl

```bash
# 注册机器人
curl -X POST "http://localhost:8000/api/robots/register?robot_id=robot1&base_url=http://10.160.128.91:1448"

# 检查注册状态
curl "http://localhost:8000/api/robots/"

# 获取机器人状态
curl "http://localhost:8000/api/robots/robot1/state"
```

### 方法3：使用诊断工具

```powershell
# 测试连接并注册
python test_robot_connection.py 10.160.128.91 robot1
```
