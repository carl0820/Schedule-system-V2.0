# 服务启动/重启指南

## Windows PowerShell 环境

### 1. 检查并安装依赖

如果遇到 `ModuleNotFoundError`，需要先安装依赖：

```powershell
# 方法1：使用国内镜像（推荐，速度快）
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 方法2：使用官方源
pip install -r requirements.txt

# 方法3：如果遇到代理问题，先禁用代理
$env:HTTP_PROXY=""
$env:HTTPS_PROXY=""
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 2. 启动服务

#### 方法1：直接运行（推荐）
```powershell
python main.py
```

#### 方法2：使用 uvicorn 命令
```powershell
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

**参数说明：**
- `--host 0.0.0.0`：监听所有网络接口
- `--port 8000`：服务端口
- `--reload`：开发模式，代码修改后自动重启

### 3. 停止服务

在运行服务的终端窗口中按：
```
Ctrl + C
```

### 4. 重启服务

#### 步骤1：停止当前服务
在运行服务的终端窗口中按 `Ctrl + C`

#### 步骤2：重新启动
```powershell
python main.py
```

### 5. 检查服务是否运行

#### 方法1：检查端口是否被占用
```powershell
netstat -ano | findstr :8000
```

#### 方法2：测试健康检查接口
```powershell
Invoke-RestMethod -Uri "http://localhost:8000/health"
```

#### 方法3：访问API文档
在浏览器中打开：http://localhost:8000/docs

### 6. 后台运行服务（可选）

如果需要让服务在后台运行：

```powershell
# 使用 Start-Process 在后台启动
Start-Process python -ArgumentList "main.py" -WindowStyle Hidden

# 或者使用 PowerShell 作业
Start-Job -ScriptBlock { python main.py }
```

查看后台作业：
```powershell
Get-Job
```

停止后台作业：
```powershell
Stop-Job -Name <作业名称>
Remove-Job -Name <作业名称>
```

## 快速启动命令

### 一键启动（如果依赖已安装）
```powershell
python main.py
```

### 一键重启（停止后重新启动）
```powershell
# 1. 停止：在服务运行的终端按 Ctrl+C
# 2. 启动：
python main.py
```

## 常见问题

### 问题1：ModuleNotFoundError: No module named 'uvicorn'
**解决方案：** 安装依赖
```powershell
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 问题1.1：Python 3.13 编译错误（metadata-generation-failed）
**错误信息：** `ERROR: Compiler c++ cannot compile programs` 或 `requires Rust and Cargo`

**原因：** Python 3.13 较新，某些旧版本的包需要从源码编译，但系统缺少编译工具。

**解决方案：** 使用 `--only-binary` 选项强制使用预编译包
```powershell
# 推荐方案：强制使用二进制包（避免编译）
pip install --only-binary :all: -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 或者分步安装
pip install --only-binary :all: fastapi uvicorn[standard] websockets httpx pydantic pydantic-settings python-multipart -i https://pypi.tuna.tsinghua.edu.cn/simple
pip install --only-binary :all: numpy redis psycopg2-binary python-jose[cryptography] passlib[bcrypt] psutil -i https://pypi.tuna.tsinghua.edu.cn/simple
```

**注意：** `requirements.txt` 已更新为使用 `>=` 版本号，会自动选择兼容 Python 3.13 的版本。

### 问题2：端口被占用
**解决方案：** 
1. 查找占用端口的进程：
```powershell
netstat -ano | findstr :8000
```
2. 结束进程（替换 PID 为实际进程ID）：
```powershell
taskkill /PID <进程ID> /F
```

### 问题3：服务启动后无法访问
**解决方案：**
1. 检查防火墙设置
2. 确认服务监听地址是否正确（应该是 `0.0.0.0` 或 `localhost`）
3. 检查端口是否正确（默认 8000）

## 验证服务运行

启动成功后，应该看到类似输出：
```
INFO:     Started server process [xxxxx]
INFO:     Waiting for application startup.
INFO:     Application startup complete.
INFO:     Uvicorn running on http://0.0.0.0:8000 (Press CTRL+C to quit)
```

然后可以访问：
- API文档：http://localhost:8000/docs
- 健康检查：http://localhost:8000/health
- 根路径：http://localhost:8000/
