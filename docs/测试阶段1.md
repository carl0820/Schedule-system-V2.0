### 步骤3：启动API服务器

启动FastAPI服务器：

```bash

```

或者使用 uvicorn：

```bash
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

**预期输出**：
```
INFO:     Started server process
INFO:     Waiting for application startup.
INFO:     Application startup complete.
INFO:     Uvicorn running on http://0.0.0.0:8000
```

### 步骤4：访问API文档

启动服务器后，在浏览器中访问：
- **API文档（Swagger）**：http://localhost:8000/docs
- **健康检查**：http://localhost:8000/health
- **根路径**：http://localhost:8000/

### 步骤5：测试API接口

#### 5.1 健康检查

```bash
curl http://localhost:8000/health
```

**预期响应**：
```json
{"status": "healthy"}
```

#### 5.2 获取系统信息

```bash
curl http://localhost:8000/
```

**预期响应**：
```json
{
  "name": "多机器人调度系统",
  "version": "1.0.0",
  "status": "running"
}
```

#### 5.3 注册机器人（需要机器人IP）

```bash
curl -X POST "http://localhost:8000/api/robots/register?robot_id=robot1&base_url=http://10.160.128.91:1448"
```

**预期响应**：
```json
{
  "message": "Robot registered successfully",
  "robot_id": "robot1"
}
```

#### 5.4 获取机器人列表

```bash
curl http://localhost:8000/api/robots/
```

#### 5.5 获取机器人状态（需要先注册机器人）

```bash
curl http://localhost:8000/api/robots/robot1/state
```

#### 5.6 获取地图信息

```bash
curl http://localhost:8000/api/maps/info
```

#### 5.7 创建任务

```bash
curl -X POST "http://localhost:8000/api/tasks/" \
  -H "Content-Type: application/json" \
  -d '{
    "target_pose": {
      "x": 5.0,
      "y": 3.0,
      "yaw": 0.0
    },
    "priority": 2
  }'
```

#### 5.8 查询任务列表

```bash
curl http://localhost:8000/api/tasks/
```

## 测试注意事项

1. **依赖安装**：确保所有依赖已安装
   ```bash
   pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
   ```

2. **机器人连接**：
   - 测试API封装时，需要机器人实际IP地址
   - 默认测试IP：`http://10.160.128.91:1448`
   - 如果机器人不在线，部分测试会显示警告但不影响功能验证

3. **地图数据**：
   - 地图数据需要从机器人获取
   - 路径规划测试可能需要实际地图数据
   - 没有地图数据时，坐标转换仍可测试

4. **数据库（可选）**：
   - Redis 和 PostgreSQL 是可选的
   - 不安装也可以运行基本功能测试

## 常见问题

### Q1: 模块导入失败
**A**: 检查依赖是否安装：
```bash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### Q2: 服务器启动失败
**A**: 检查端口是否被占用，或修改 `config.py` 中的端口号

### Q3: 机器人API调用失败
**A**: 
- 检查机器人IP地址是否正确
- 检查网络连接
- 查看机器人是否在线

### Q4: 路径规划返回空路径
**A**: 
- 检查起始点和目标点是否在地图范围内
- 检查是否有障碍物阻挡
- 确保地图数据已加载
