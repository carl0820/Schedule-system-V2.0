# 服务管理脚本使用指南

本项目提供了三个 PowerShell 脚本，用于快速管理机器人调度系统服务。

## 脚本列表

### 1. `start_service.ps1` - 启动服务

启动机器人调度系统服务。

**使用方法：**
```powershell
# 前台运行（显示窗口）
.\start_service.ps1

# 后台运行（不显示窗口）
.\start_service.ps1 -Background
```

**功能：**
- 检查端口 8000 是否已被占用
- 如果已占用，询问是否强制停止并重启
- 自动检测并使用虚拟环境中的 Python
- 启动服务后验证服务状态
- 显示服务访问地址

**示例输出：**
```
========================================
  启动机器人调度系统服务
========================================

✓ 使用虚拟环境: venv\Scripts\python.exe
正在启动服务...
✓ 服务已启动 (进程ID: 12345)

========================================
  服务启动成功！
========================================

  进程ID: 12345
  服务地址: http://localhost:8000
  API文档: http://localhost:8000/docs
  主页: http://localhost:8000/
```

---

### 2. `stop_service.ps1` - 停止服务

停止正在运行的机器人调度系统服务。

**使用方法：**
```powershell
# 交互式停止（会询问确认）
.\stop_service.ps1

# 强制停止（不询问确认）
.\stop_service.ps1 -Force
```

**功能：**
- 查找并显示占用端口 8000 的进程信息
- 询问确认后停止服务
- 验证服务是否已完全停止
- 如果仍有进程占用，提供强制停止选项

**示例输出：**
```
========================================
  停止机器人调度系统服务
========================================

发现运行中的服务进程:
  进程ID: 12345
  进程名: python
  命令行: python main.py

确定要停止这些服务吗? (Y/n): y
正在停止服务...
✓ 已停止进程 12345

========================================
  服务已成功停止
========================================
```

---

### 3. `restart_service.ps1` - 重启服务

重启机器人调度系统服务（先停止，再启动）。

**使用方法：**
```powershell
# 前台运行（显示窗口）
.\restart_service.ps1

# 后台运行（不显示窗口）
.\restart_service.ps1 -Background

# 强制停止并重启（不询问确认）
.\restart_service.ps1 -Force
```

**功能：**
- 自动停止现有服务
- 等待进程完全退出
- 启动新服务
- 验证服务状态
- 显示服务访问地址

**示例输出：**
```
========================================
  重启机器人调度系统服务
========================================

[1/2] 停止现有服务...

发现运行中的服务进程: 12345
✓ 已停止进程 12345
✓ 已停止 1 个进程

[2/2] 启动新服务...

✓ 使用虚拟环境: venv\Scripts\python.exe
正在启动服务...
✓ 服务已启动 (进程ID: 12346)

========================================
  服务重启成功！
========================================
```

## 快速使用

### 日常使用场景

1. **启动服务**（首次启动或服务停止后）
   ```powershell
   .\start_service.ps1
   ```

2. **停止服务**（需要停止服务时）
   ```powershell
   .\stop_service.ps1
   ```

3. **重启服务**（应用代码更新后）
   ```powershell
   .\restart_service.ps1
   ```

### 高级用法

1. **后台启动服务**（不显示窗口）
   ```powershell
   .\start_service.ps1 -Background
   ```

2. **强制停止服务**（不询问确认）
   ```powershell
   .\stop_service.ps1 -Force
   ```

3. **强制重启服务**（后台运行，不询问确认）
   ```powershell
   .\restart_service.ps1 -Force -Background
   ```

## 注意事项

1. **执行策略**
   - 如果遇到"无法加载脚本"的错误，需要设置执行策略：
   ```powershell
   Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
   ```

2. **工作目录**
   - 确保在项目根目录下运行这些脚本
   - 脚本会自动检测 `main.py` 文件

3. **虚拟环境**
   - 脚本会自动检测并使用虚拟环境中的 Python
   - 如果未找到虚拟环境，会使用系统 Python（会显示警告）

4. **端口占用**
   - 如果端口 8000 被其他程序占用，脚本会提示并询问是否强制停止

5. **服务验证**
   - 启动后会尝试检查服务健康状态
   - 如果服务仍在启动中，健康检查可能失败（这是正常的）

## 故障排查

### 问题1: 脚本无法执行
**错误**: `无法加载脚本，因为在此系统上禁止运行脚本`

**解决方案**:
```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

### 问题2: 服务启动失败
**可能原因**:
- Python 未安装或不在 PATH 中
- 虚拟环境未创建
- 依赖包未安装
- 端口 8000 被占用

**解决方案**:
1. 检查 Python 是否安装: `python --version`
2. 检查虚拟环境: `Test-Path venv\Scripts\python.exe`
3. 检查端口占用: `netstat -ano | findstr :8000`
4. 查看日志: `Get-Content logs\app.log -Tail 50`

### 问题3: 服务停止失败
**可能原因**:
- 进程被锁定
- 权限不足

**解决方案**:
1. 使用 `-Force` 参数强制停止
2. 以管理员身份运行 PowerShell
3. 手动结束进程: `taskkill /F /PID <进程ID>`
