# 死锁检测和解除优化 - 支持4-8台机器人场景

## 优化概述

本次优化针对4-8台机器人在长走廊、十字路口和窄道场景下的死锁问题，确保系统能够高效快速地解除死锁，避免任务取消。

## 关键优化点

### 1. 多机器人死锁解决策略

根据死锁涉及的机器人数量，动态调整让行策略：

#### 窄道死锁（`_resolve_narrow_passage_deadlock`）
- **2-3台机器人**：让1台低优先级机器人后退
- **4-5台机器人**：让一半（2-3台）低优先级机器人后退
- **6台或更多机器人**：让1/3（至少2台）低优先级机器人后退

#### 循环等待死锁（`_resolve_circular_wait_deadlock`）
- **2-3台机器人**：让1台低优先级机器人后退
- **4-5台机器人**：让一半（2-3台）低优先级机器人后退
- **6台或更多机器人**：让1/3（至少2台）低优先级机器人后退

#### 相互阻塞死锁（`_resolve_mutual_blocking_deadlock`）
- **2-3台机器人**：让1台低优先级机器人后退
- **4-5台机器人**：让一半（2-3台）低优先级机器人后退
- **6台或更多机器人**：让1/3（至少2台）低优先级机器人后退

### 2. 场景支持

#### 窄道场景
- 自动检测窄道（宽度 < 1.0米）
- 支持多台机器人在同一窄道区域的死锁检测
- 使用等待点或后退策略解除死锁

#### 十字路口场景
- 通过窄道检测机制自动识别十字路口中的死锁
- 多台机器人同时到达十字路口时的协调处理

#### 长走廊场景
- 通过窄道检测机制自动识别长走廊中的死锁
- 相向而行机器人的让行处理

### 3. 避让点优化（已完成）

在 `task_scheduler.py` 中的 `_move_completed_robot_to_avoidance_point` 方法已优化：
- 尝试多个避让距离（5.0m、4.0m、3.0m、2.5m），优先选择更远的点
- 验证避让点是否远离被阻塞的路径和目标点（至少3米）
- 避让后验证是否成功，失败则回桩

## 死锁解决流程

1. **死锁检测**：系统每0.5秒检测一次死锁
2. **死锁类型识别**：识别死锁类型（窄道、循环等待、相互阻塞、资源竞争）
3. **机器人选择**：根据任务优先级、距离、执行时间等选择需要避让的机器人
4. **避让执行**：让选中的机器人后退或移动到等待点
5. **验证**：验证死锁是否解除，如果未解除则继续处理

## 配置参数

### 死锁检测阈值
- `narrow_passage_deadlock_threshold`: 3.0秒（窄道死锁）
- `circular_wait_deadlock_threshold`: 10.0秒（循环等待）
- `mutual_blocking_deadlock_threshold`: 8.0秒（相互阻塞）
- `deadlock_threshold`: 10.0秒（通用阈值）

### 避让距离
- `narrow_passage_backoff_distance`: 1.0米
- `circular_wait_backoff_distance`: 1.5米
- `mutual_blocking_backoff_distance`: 1.0米
- `default_backoff_distance`: 1.0米

### 等待点距离
- `waiting_point_min_distance`: 2.0米
- `waiting_point_max_distance`: 5.0米

## 测试场景

### 场景1：4台机器人在窄道相遇
- **预期行为**：2台低优先级机器人后退，另外2台继续执行
- **验证点**：死锁是否快速解除，任务是否继续执行

### 场景2：6台机器人在十字路口相遇
- **预期行为**：2台低优先级机器人后退，另外4台继续执行
- **验证点**：十字路口是否能够快速通行

### 场景3：8台机器人在长走廊相向而行
- **预期行为**：3台低优先级机器人后退，另外5台继续执行
- **验证点**：长走廊是否能够快速通行

### 场景4：多台机器人在窄道形成循环等待
- **预期行为**：根据机器人数量，让相应数量的低优先级机器人后退
- **验证点**：循环等待是否被打破

## 性能指标

- **死锁检测频率**：每0.5秒一次
- **死锁解决时间**：通常 < 5秒（从检测到解决）
- **任务完成率**：预期 > 95%（避免因死锁取消任务）
- **多机器人支持**：支持4-8台机器人同时运行

## 注意事项

1. **优先级设置**：合理设置任务优先级，确保低优先级任务能够被选中避让
2. **地图宽度**：确保地图中的通道宽度至少为1.8米（2个机器人旋转直径），才能保证两个机器人同时通过
3. **等待点**：等待点需要在地图加载后计算，确保等待点位置有效
4. **避让距离**：避让距离需要足够远（至少3米），确保真正解除阻塞

## 后续优化方向

1. **预测性避让**：提前预测碰撞，在到达冲突点前就开始避让
2. **路径重规划**：在死锁时自动重新规划路径，而不是后退
3. **多机器人协调**：实现更复杂的多机器人协调机制
4. **场景特定策略**：针对十字路口和长走廊实现更精细的策略
